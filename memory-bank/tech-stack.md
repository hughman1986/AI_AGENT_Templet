## 核准技術棧

> 專案正式技術設定的唯一來源。空白或「待確認」不代表核准；`templates/` 候選範例不會自動生效。

* 語言 / 執行環境與版本：待確認
* 框架 / UI：待確認（不適用可註明）
* 資料儲存：待確認（不適用可註明）
* 開發 / 執行環境：待確認
* 核准來源（使用者決策或既有專案依據）：待確認

## 依賴政策

* 優先使用專案現有且已核准的依賴，不因範例列出套件就新增。
* 新增依賴前說明用途、替代方案、相容性、維護與授權狀態，取得專案負責人核准。
* 已有明確核准不重複詢問；待核准項目不得列為已核准。
* 核准依賴與版本 / 用途 / 核准來源：待確認

## 測試與執行

* 已核准測試工具：待確認
* 環境準備與啟動命令：待確認
* 自動化測試命令：待確認

## 安全與效能需求

* 適用的驗證、授權與資料保護要求：待確認
* 效能指標與門檻：待確認；未確認前不套用候選數字
* 量測條件（環境、資料量、負載與量測方式）：待確認
* 需求 / 核准來源：待確認
